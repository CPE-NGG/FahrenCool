Connection Architecture

Browser dashboard → authenticated LCD API or secure proxy → Sunton LCD ESP32 → ESP-NOW → standalone ESP32 → pump, fan and TEC.

This HTML supplies the interface and API adapter. Real operation requires matching routes on the LCD or a secure backend, plus firmware-side validation and independent temperature and hardware safety protections.
